# Screenshots

Add screenshots of the running application here for your project report or viva demonstration.

Suggested filenames (referenced from the main `README.md`):

- `dashboard.png`
- `projects.png`
- `project-details.png`
- `tasks.png`
- `calendar.png`
- `team.png`
- `reports.png`

To capture a screenshot: run `npm run dev`, open the app in your browser, navigate to the page, and use your OS screenshot tool (e.g. `Win + Shift + S` on Windows, `Cmd + Shift + 4` on Mac).
